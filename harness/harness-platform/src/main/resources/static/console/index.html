与终端里的智能体对话

在下面选一台终端，说人话就行。智能体会用它被授予的能力去做事 （读文件、改文件、跑命令），做完把结果和改过的文件发回来。没被授权的动作会被拒绝—— 这是设计如此，不是故障。

大脑是平台自己的运维助手：数字员工、终端、授权、审批、事件、 审计，它都能查。它只看不动——要改的事它会告诉你在控制台哪里点。

与平台大脑对话

回车发送。它会自己去查数据，回答基于平台当前状态。
临时授权 TTL ≤ 24h，超限会被拒绝（不是截短）。
技能是内容不是授权：装上去也不会多出任何能力，每一步动作照样过策略。

已拉取部署

外部注册源

外部内容一律先进候选池，要另一个人评审过才能上架。 跨组织的共享从显式授权开始，不做自动发现。

不可逆动作需要两名不同的自然人签字；驳回不需要理由门槛，批准需要。
